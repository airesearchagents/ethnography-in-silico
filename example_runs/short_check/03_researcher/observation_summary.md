# Researcher observation summary

## Decisions
- Move beyond conversational chat interfaces to build a foundational platform for Proactive Autonomous Agents under an Execution-as-a-Service model.
- Target Software Engineering and Data Science via the AI Scientist as the V1 beachhead vertical to leverage automated feedback loops.
- Transition from predictable per-seat SaaS to a utility-style compute-based pricing model where customers rent dedicated GPU capacity.
- Ring-fence 15-20% of the upcoming GPU cluster for unproven experimental agentic loops.
- Reject the development of native Ambient Spatial Hardware (AR/VR).
- Reject horizontal prosumer and SMB agents for low-stakes tasks.
- Implement an asynchronous Mission Control Dashboard with an Audit Trail and Interrupt & Clarify workflows.
- Pilot a Tunable Oversight framework to build enterprise trust.

## Disagreements
- **Ambient Spatial Collaborator versus Proactive Autonomous Agents** between Product_Designer, CTO, Product_Strategist, COO → _The Product Designer aligned with the consensus to drop the AR/VR push and design for the really smart senior co-worker paradigm._
- **Targeting the AI Diagnostician versus the AI Scientist for the first agentic product** between CEO, CMO, COO, Product_Strategist → _The CEO officially pivoted the V1 beachhead to the AI Scientist to mitigate regulatory and brand risk._
- **Streaming real-time telemetry versus maintaining deep inference efficiency** between Product_Designer, CTO → _Decided to implement Asynchronous Batch Updates rather than streaming telemetry natively in sub-second real-time._
